## 一、SMART 总目标

| 维度 | 面试手撕目标 |
|---|---|
| S 具体 | 掌握数组、链表、哈希、双指针、滑窗、栈/单调栈、二分、排序、堆、树、回溯、贪心、动态规划、矩阵 14 条主线，以及 C++ 常用 STL 写法 |
| M 可度量 | 首轮完成 40 道 P0/P1 代表题；每道题能在 3 分钟内说出思路、状态/不变量和复杂度；能在 20 分钟内独立写完并通过边界自测 |
| A 可实现 | 采用“模板题 + 变式题 + 限时复写”的小批量训练，每天 2 个主题或 4～6 道高质量题，不追求盲目刷题量 |
| R 相关 | 优先覆盖面试最常见的原地操作、链表指针、哈希映射、区间/窗口、树递归、搜索剪枝和一维/二维 DP |
| T 有期限 | 7 天完成首轮，14 天完成第二轮错题复写；面试前 24 小时只复习模板、错题和易错边界 |

### 首轮完成标准

不要用“看完题解”作为完成标准。每道核心题至少留下以下记录：

1. 题型识别信号：看到什么条件会想到该模板。
2. 核心不变量：循环或递归过程中始终成立的事实。
3. 代码骨架：能脱离题解写出。
4. 复杂度：时间、空间，以及是否包含输出空间。
5. 边界用例：至少覆盖空输入、单元素、重复值、极值或特殊结构。
6. 一句话表达：能向面试官解释为什么这样做不会漏解。

## 三、面试手撕通用流程

### 1. 读题：先确认约束

先问自己四件事：

- 输入规模是多少？`n` 是 `10^3`、`10^5` 还是更大？
- 是否要求原地、常数额外空间、稳定顺序或不能修改输入？
- 是否有重复值、负数、空输入、多个答案、答案需要去重？
- 输出是值、下标、节点、路径、所有方案，还是最优值？

复杂度决策可以先粗略判断：

| 规模/要求 | 优先考虑 |
|---|---|
| `n <= 20` | 回溯、状态压缩、指数级搜索的剪枝 |
| `n <= 10^3` | O(n²)、二维 DP、排序后双指针 |
| `n <= 10^5` | O(n)、O(n log n)、哈希、堆、单调栈 |
| 要求 O(1) 额外空间 | 原地交换、索引映射、反转、位标记、快慢指针 |
| 要求返回全部方案 | 回溯/排序去重，并单独计算输出规模 |

### 2. 表达：先说方案，再写代码

推荐用四句开场：

1. “这题的关键是……，我会使用……。”
2. “我维护的不变量是……。”
3. “每个元素最多被……次处理，所以时间复杂度是……。”
4. “我会重点验证……几个边界。”

### 3. 编码：按固定顺序

1. 写函数签名和必要的数据结构。
2. 处理空输入、单元素和特殊参数。
3. 写主循环/递归骨架。
4. 在关键更新旁边写一句不变量注释。
5. 最后补复杂度和自测，不要边写边大规模重构。

### 4. 验证：至少跑五类用例

- 最小输入：空数组、一个元素、空树、空链表。
- 最简单成功：明显能得到答案的样例。
- 最简单失败：没有答案、无法匹配、无法组成。
- 重复/极值：重复元素、全相同、全负数、整数溢出风险。
- 结构边界：偶数/奇数长度、单行/单列、完全左斜树/右斜树、环在头部。

## 四、C++ 手撕基础模板

### 1. 常用头文件与别名

```cpp
#include <algorithm>
#include <climits>
#include <functional>
#include <queue>
#include <stack>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <utility>
#include <vector>
using namespace std;
```

优先熟练以下接口：

| 需求 | C++ 写法 |
|---|---|
| 排序/反转 | `sort(v.begin(), v.end())`、`reverse(v.begin(), v.end())` |
| 哈希计数 | `unordered_map<int, int> cnt; ++cnt[x];` |
| 查找 | `mp.find(x) != mp.end()`、`st.count(x)` |
| 堆 | `priority_queue<int> maxHeap;`、`priority_queue<int, vector<int>, greater<int>> minHeap;` |
| 队列/栈 | `queue<T>`、`stack<T>` |
| 二分 | `lower_bound`、`upper_bound`，或手写闭区间模板 |
| 安全中点 | `int mid = left + (right - left) / 2;` |

### 2. 二分模板

题目出现“有序”“单调”“第一个满足条件”“最小可行值”时，先定义答案区间和谓词，再决定闭区间还是半开区间。面试中推荐统一使用闭区间：

```cpp
int left = 0, right = n - 1;
while (left <= right) {
    int mid = left + (right - left) / 2;
    if (check(mid)) {
        // 根据题意保留或收缩答案区间
        right = mid - 1;
    } else {
        left = mid + 1;
    }
}
```

关键不是背 `left` 或 `right` 返回哪个，而是明确：

- `check(mid)` 为真时，答案在左边还是右边；
- 循环结束时，`left` 和 `right` 分别代表什么；
- 不存在答案时如何返回。

### 3. 链表反转与虚拟头节点

```cpp
ListNode dummy(0, head);
ListNode* prev = &dummy;
ListNode* cur = head;
while (cur) {
    ListNode* next = cur->next;
    cur->next = prev;
    prev = cur;
    cur = next;
}
```

写链表题时更推荐先画出 `prev / cur / next` 三个指针的方向。涉及删除头节点、合并链表、分组翻转时优先考虑虚拟头节点，减少头节点特殊分支。

## 五、题型识别与核心模板

### P0-1 数组、哈希和前缀和

#### 识别信号

- “是否出现过”“出现次数”“两数之和”“前 K 高频”优先想到哈希。
- “连续子数组和为 K”优先想到前缀和 + 频次哈希。
- “不允许额外空间”“找缺失/重复”优先检查索引映射或原地标记。
- “除自身以外乘积”要求无除法时，用前缀积和后缀积。

#### 核心模板

```cpp
// 前缀和 + 频次：统计和为 k 的连续子数组
unordered_map<long long, int> freq;
freq[0] = 1;
long long prefix = 0;
int ans = 0;
for (int x : nums) {
    prefix += x;
    if (freq.count(prefix - k)) ans += freq[prefix - k];
    ++freq[prefix];
}
```

```cpp
// 原地标记：最小缺失正数
int n = nums.size();
for (int& x : nums) {
    if (x <= 0 || x > n) x = n + 1;
}
for (int x : nums) {
    int v = abs(x);
    if (v <= n) nums[v - 1] = -abs(nums[v - 1]);
}
for (int i = 0; i < n; ++i) {
    if (nums[i] > 0) return i + 1;
}
return n + 1;
```

#### 代表题

- `两数之和`：记录互补值或记录已出现值，注意下标从 0 还是从 1 开始。
- `和为 K 的子数组`：`prefix[j] - prefix[i] = k`，哈希必须存频次而不只是最后位置。
- `轮转数组`：整体反转，再反转前 `k % n` 个和剩余部分。
- `除自身以外数组的乘积`：输出数组存左积，反向变量累乘右积；不要使用除法。
- `缺失的第一个正数`：答案一定在 `[1, n + 1]`，把值映射到下标。

#### 易错点

- 前缀和可能溢出，必要时使用 `long long`。
- 哈希表更新顺序会影响是否使用当前元素，先查询后计数通常更清晰。
- `k % n` 前先处理空数组。
- 原地负号标记前要使用 `abs`，避免重复标记把正负关系弄乱。

### P0-2 双指针与滑动窗口

#### 识别信号

- 两端向中间移动，数据有序或存在单调关系：首尾双指针。
- “连续子串/子数组 + 最长/最短 + 满足条件”：滑动窗口。
- “三数之和/四数之和”：排序 + 固定一个或多个元素 + 双指针。
- “合并两个有序数组且原地”：从尾部向前填充。

#### 首尾双指针模板

```cpp
int left = 0, right = nums.size() - 1;
while (left < right) {
    // 根据单调性排除不可能的区间
    if (condition) {
        ++left;
    } else {
        --right;
    }
}
```

#### 可变窗口模板

```cpp
int left = 0;
for (int right = 0; right < n; ++right) {
    add(nums[right]);
    while (!valid()) {
        remove(nums[left]);
        ++left;
    }
    ans = max(ans, right - left + 1); // 或记录最小长度
}
```

#### 代表题与关键不变量

- `合并两个有序数组`：从尾部放置较大值，避免覆盖 A 中尚未处理的元素。
- `盛最多水的容器`：移动较短的一侧；宽度减少时，移动较高一侧不可能得到更高容量。
- `接雨水`：当前位置水量是左右最高柱较小值减当前高度；可用前后缀数组，也可优化为双指针。
- `三数之和`：排序后固定 `i`，左右夹逼；固定层、左指针、右指针都要按条件去重。
- `无重复字符的最长子串`：窗口内始终无重复字符；重复时左边界跳到上次出现位置之后。
- `找到所有字母异位词`：固定窗口长度，维护字符频次数组。

#### 易错点

- 窗口收缩条件是 `while` 还是 `if`，取决于收缩后是否必须恢复合法。
- 滑窗通常要求连续区间，不能误用子序列思路。
- 三数之和去重不能只在结果集层面做，否则可能重复枚举。
- “移动较小指针”的结论必须有单调性依据，不能机械套用。

### P0-3 链表

#### 必会操作

1. 虚拟头节点：统一处理头部删除、插入和合并。
2. 三指针反转：`prev / cur / next`。
3. 快慢指针：找中点、判环、找环入口、判断回文。
4. 长度对齐：相交链表先对齐长度，或使用“双指针切换头节点”。
5. 双向链表 + 哈希表：实现 LRU，哈希负责 O(1) 定位，链表负责 O(1) 移动和淘汰。

#### 代表题

- `相交链表`：比较节点地址而不是节点值；双指针各走 A+B 后会对齐。
- `回文链表`：快慢指针找中点，反转后半段，比较后恢复链表。
- `K 个一组翻转链表`：先确认当前组有 K 个节点，再翻转并接回下一组。
- `随机链表的复制`：哈希表记录原节点到新节点的映射；递归访问时要先建立映射再连边。
- `环形链表 II`：快慢指针相遇后，一个指针回到头部，同速前进，下一次相遇即入口。
- `LRU 缓存`：虚拟头尾节点 + `unordered_map<Key, Node*>`。
- `两数相加`：同步遍历、维护进位、最后检查进位。

#### 链表自检清单

- 是否可能删除头节点？
- 是否可能为空链表？
- 是否在保存 `next` 前修改了 `cur->next`？
- 返回的是节点地址还是节点值？
- 是否改变了原链表结构？题目要求保持不变时是否恢复？
- 新建的哨兵节点是否造成无意义泄漏？手撕时可用栈上 dummy。

### P0-4 栈、队列与单调栈

#### 识别信号

- 括号、嵌套、逆序处理：栈。
- “右侧/左侧第一个更大或更小”：单调栈。
- “连续区间最大值/最小值”可能是单调队列，当前材料重点先掌握单调栈。

#### 单调栈模板

```cpp
vector<int> ans(n, 0);
stack<int> st; // 保存下标，保持对应值单调
for (int i = 0; i < n; ++i) {
    while (!st.empty() && nums[i] > nums[st.top()]) {
        ans[st.top()] = i - st.top();
        st.pop();
    }
    st.push(i);
}
```

#### 代表题

- `最小栈`：辅助栈同步记录每一层最小值，所有操作 O(1)。
- `字符串解码`：遇到 `[` 保存外层字符串和重复次数，遇到 `]` 组合当前层。
- `每日温度`：维护尚未找到更高温度的下标，当前温度触发出栈。
- `柱状图最大矩形`：维护递增高度栈；出栈时当前下标确定右边界，新的栈顶确定左边界；首尾加 0 简化边界。

#### 易错点

- 栈里存值还是存下标要先确定；需要距离或宽度时必须存下标。
- `while` 出栈后要再次检查新的栈顶。
- 相等高度如何处理要统一：保留后者或弹出前者，不能前后混用。
- 栈中剩余元素的答案通常要用哨兵或额外循环处理。

### P0-5 二叉树

#### 递归四问

写递归前先明确：

1. 函数定义：`dfs(node, state)` 返回什么？
2. 空节点返回什么？
3. 当前节点做什么？
4. 左右子树返回值如何合并？

#### 遍历模板

```cpp
void dfs(TreeNode* node) {
    if (!node) return;
    // 前序位置：处理当前节点
    dfs(node->left);
    // 中序位置：处理当前节点
    dfs(node->right);
    // 后序位置：处理左右子树结果
}
```

```cpp
queue<TreeNode*> q;
if (root) q.push(root);
while (!q.empty()) {
    int size = q.size(); // 当前层节点数
    while (size--) {
        TreeNode* node = q.front();
        q.pop();
        if (node->left) q.push(node->left);
        if (node->right) q.push(node->right);
    }
}
```

#### 代表题

- `二叉搜索树第 K 小`：BST 中序遍历天然升序，递归或显式栈都可以。
- `路径总和 III`：基础解法是每个节点作为起点的双层递归；更高效变式是前缀和哈希。
- `前序与中序构造二叉树`：前序第一个是根，中序根左侧是左子树，右侧是右子树；实际编码可用哈希表保存中序位置，避免反复切 vector。
- `二叉树右视图`：层序每层取最后一个，或 DFS 先右后左并记录首次到达的深度。

#### 易错点

- 题目是节点数、深度、路径和还是路径列表，返回值定义不同。
- 路径是否必须从根到叶、是否允许从任意节点开始，要读清楚。
- 递归参数按值传递还是引用传递，尤其是 `k`、计数器和路径数组。
- 节点值可能为负数时，不能用“当前和超过 target 就剪枝”的错误假设。

### P0-6 动态规划

#### 动规五步法

1. 定义 `dp` 的含义，必须能用一句完整中文说清。
2. 写出最后一步如何转移到前一步。
3. 确定初始化，并保证和定义一致。
4. 确定遍历顺序，区分完全背包、0/1 背包和区间 DP。
5. 用小样例手推 3～5 个状态，检查转移是否合理。

#### 一维 DP 模板

```cpp
vector<int> dp(n + 1, 0);
// dp[i] = 前 i 个/达到状态 i 的最优值
for (int i = 1; i <= n; ++i) {
    dp[i] = ...;
}
```

#### 代表题分组

| 类型 | 代表题 | 关键点 |
|---|---|---|
| 相邻不能同时选 | 打家劫舍 | `dp[i] = max(dp[i-1], dp[i-2] + value)`，可滚动优化 |
| 完全背包/最少数量 | 零钱兑换、完全平方数 | `dp[0]` 为 0，其余用不可达值初始化 |
| 字符串可达性 | 单词拆分 | `dp[i]` 表示前缀能否拆分，哈希集合加速查词 |
| 子序列 | 最长递增子序列、最长公共子序列 | 明确“连续”还是“不连续”，二维状态含义不同 |
| 局部状态双轨 | 乘积最大子数组 | 同时维护当前最大值和最小值，负数会交换二者 |
| 网格路径 | 最小路径和 | 由上方/左方转移，初始化首行首列 |
| 区间/回文 | 最长回文子串 | 状态通常依赖更短区间，注意遍历顺序 |
| 编辑操作 | 编辑距离 | 插入、删除、替换三种转移 |
| 括号状态 | 最长有效括号 | 栈更直观，DP 作为进阶方案掌握 |

#### DP 易错点

- 把“子数组/子串”误写成“子序列”。
- 不可达状态初始化成 0，导致错误地认为状态可达。
- `INT_MAX + 1` 溢出；加一前先判断是否可达。
- 题目要求最少值时取 `min`，要求最多值时取 `max`，存在性问题使用布尔状态。
- 空输入和长度为 1 时，初始化不能直接访问 `nums[0]`。

### P1-1 排序

#### 面试必须会写

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 | 重点 |
|---|---:|---:|---:|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 | 可用交换标志提前结束 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 | 每轮找最小值 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 | 近乎有序时较好 |
| 快速 | O(n log n) | O(n²) | O(log n) 平均 | 不稳定 | 分区、递归边界、基准选择 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 | 两个有序区间合并 |
| 堆排序 | O(n log n) | O(n log n) | O(1) | 不稳定 | 建堆从最后一个非叶节点开始 |

手撕时优先掌握快速排序和归并排序。若题目只要求调用排序，不要为了展示手写算法而牺牲正确性；若面试官明确要求手写，再写核心版本并说明复杂度。

#### 快速排序不变量

- 选定 pivot 后，分区完成时 pivot 左侧不大于它，右侧不小于它。
- 递归区间必须严格缩小。
- 已排序、全相同数据可能造成 O(n²)，可提到随机 pivot、三数取中或三路快排。

#### 归并排序不变量

- 两个待合并区间各自有序。
- 每次把较小的当前元素写入临时数组。
- 一个区间耗尽后，另一个区间剩余元素直接追加。

### P1-2 堆与优先队列

#### 识别信号

- 动态维护最大/最小值。
- Top K、数据流中位数、反复取当前最优元素。
- 需要排序但不要求完整有序，或只保留 K 个候选。

#### 常用写法

```cpp
priority_queue<int> maxHeap;
priority_queue<int, vector<int>, greater<int>> minHeap;
```

#### 代表题

- `第 K 个最大元素`：维护大小为 K 的小顶堆，复杂度 O(n log K)；若严格要求平均 O(n)，掌握快速选择。
- `前 K 个高频元素`：哈希统计频次，再用大小为 K 的堆；材料中也涉及桶排序。
- `数据流的中位数`：大顶堆保存较小一半，小顶堆保存较大一半，保持两堆大小差不超过 1。

#### 易错点

- `priority_queue` 默认是大顶堆，比较器方向容易写反。
- 只需要 Top K 时，不必把所有元素放入大堆。
- 中位数两堆的顺序、数量平衡和偶数平均值要同时维护。

### P1-3 回溯

#### 通用模板

```cpp
void backtrack(State& state) {
    if (finished(state)) {
        results.push_back(makeAnswer(state));
        return;
    }
    for (Choice choice : choices(state)) {
        if (!valid(choice, state)) continue;
        apply(choice, state);
        backtrack(state);
        undo(choice, state);
    }
}
```

#### 代表题

- `括号生成`：左括号数不能超过 n，右括号数不能超过左括号数。
- `单词搜索`：网格 DFS，访问时标记，递归返回后恢复；同一格不能重复使用。

#### 回溯四要素

1. 路径：当前已经做出的选择。
2. 选择列表：下一步可以尝试什么。
3. 结束条件：什么时候形成完整答案。
4. 剪枝条件：哪些状态已经不可能成功。

### P1-4 矩阵与原地技巧

- `矩阵置零`：第一行和第一列作为标记位，但必须先记录它们原本是否含 0。
- `螺旋矩阵`：维护 `up/down/left/right` 四个边界，每走完一条边立即检查是否越界。
- `旋转图像`：上下翻转 + 主对角线转置，或转置 + 每行反转。
- `搜索二维矩阵 II`：从右上角出发；当前值大于 target 向左，小于 target 向下。

原地题的统一思路：

1. 找到可以复用的标记空间。
2. 先保护会被覆盖的元信息。
3. 读写顺序不能破坏尚未处理的数据。
4. 明确每个位置处理一次还是多次。

### P1-5 贪心与技巧

| 题型 | 核心 |
|---|---|
| 买卖股票的最佳时机 | 扫描过程中维护历史最低买入价，更新当前最大收益 |
| 只出现一次的数字 | 异或满足交换律、结合律，`x ^ x = 0`、`x ^ 0 = x` |
| 两个只出现一次的数字 | 先整体异或，取最低位不同位将数字分组再分别异或 |
| 多数元素 | 摩尔投票：不同元素两两抵消，多数元素最终保留 |
| 颜色分类 | 荷兰国旗三指针，维护 0 区、1 区、未处理区、2 区 |
| 下一个排列 | 找最长非增后缀，交换拐点和右侧刚好更大的值，再反转后缀 |

贪心题不能只说“每一步选最优”。需要补充：

- 当前选择排除了什么情况；
- 为什么不会损失全局最优；
- 是否依赖排序或某个单调性；
- 是否存在反例，如何验证。

## 九、复杂度与正确性表达

### 通用表达模板

> 我维护了……，因此每次循环开始时……始终成立。每个元素最多入栈/出栈一次，或者左右指针各只向前移动，所以总时间复杂度是 O(n)。辅助结构最多保存 n 个元素，空间复杂度是 O(n)；如果只计算额外空间，输出数组不计入/需要计入，取决于题目约定。

### 高频复杂度对照

| 方法 | 时间 | 额外空间 | 典型题 |
|---|---:|---:|---|
| 暴力双循环 | O(n²) | O(1) | 小规模数组 |
| 排序 + 双指针 | O(n log n) | O(1)～O(n) | 三数之和 |
| 哈希一次扫描 | 平均 O(n) | O(n) | 两数之和 |
| 前缀和 + 哈希 | O(n) | O(n) | 和为 K 子数组 |
| 单调栈 | O(n) | O(n) | 每日温度、柱状图 |
| 堆维护 Top K | O(n log K) | O(K) | 前 K 高频 |
| 归并排序 | O(n log n) | O(n) | 稳定排序 |
| 快速排序 | 平均 O(n log n) | 平均 O(log n) | 原地排序 |
| 二维 DP | O(mn) | O(mn) 或 O(n) | LCS、最小路径和 |

## 十一、面试前 30 分钟速记

- 哈希：查补数、计频次、记前缀和出现次数；需要多个答案时不要覆盖历史频次。
- 双指针：先找单调性，再决定移动哪一侧；三数之和排序后注意三层去重。
- 滑窗：窗口表示什么，什么时候扩张，什么时候收缩，收缩后是否一定合法。
- 链表：虚拟头节点、保存 `next`、比较节点地址、快慢指针、恢复结构。
- 单调栈：栈存下标；出栈时确定右边界，新栈顶确定左边界。
- 二分：先定义 `check(mid)` 和区间含义，再写边界。
- 树：空节点返回值、递归函数含义、前中后序位置、层序按层处理。
- DP：状态定义、转移、初始化、遍历顺序、是否可滚动优化。
- 堆：默认大顶堆；Top K 通常维护大小为 K 的小顶堆。
- 回溯：路径、选择、结束、剪枝、撤销。
- 原地：先保护会被覆盖的信息，再使用数组自身作为标记。
- C++：使用 `long long` 防溢出；检查 `empty()`、下标边界和 `nullptr`。
